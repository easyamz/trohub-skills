# TROHUB Skills

Agent Skills for the TROHUB IP-checking API — for cross-border e-commerce sellers.
Works with Claude Code, Codex CLI, and any tool supporting the open Agent Skills format.

## Install

**Claude Code**
\`\`\`bash
cp -r trohub-ip-check ~/.claude/skills/        # global
cp -r trohub-ip-check .claude/skills/          # project
\`\`\`

**Codex CLI**
\`\`\`bash
cp -r trohub-ip-check ~/.codex/skills/
\`\`\`

## What's included
- `trohub-ip-check/SKILL.md` — main skill instructions
- `trohub-ip-check/scripts/trohub_client.py` — ready-to-run Python client + CLI
- `trohub-ip-check/references/` — detailed API reference per module

See [`trohub-ip-check/SKILL.md`](./trohub-ip-check/SKILL.md) for full documentation.
